# cfquant 官网更新记录

## site_20260831_03

- 文档页卡片恢复为可点击入口，统一跳转到官网内部 `/docs/*.html` 文档页。
- 新增站内文档页：部署指南、外部 Python 接入、miniQMT 迁移、运维更新、接口兼容、排障路径。

## site_20260831_02

- 文档页卡片改为站内静态入口，不再点击整张卡片跳转 GitHub。
- 文档页说明改为站内阅读与排障路径，保留下载页和顶部 GitHub 作为显式备用入口。

## site_20260831_01

- 公开官网切换为 Opendesign 交付的新 UI 方案，保留“项目、下载、文档、论坛、反馈、用户中心”结构。
- 新 UI 已接入现有官网 API：下载与最新版本、社区统计、论坛分类/帖子/回复、公开反馈/我的反馈、登录注册、用户中心和通知。
- 管理后台 `/95ge` 独立引用 `admin.css`，避免公开官网新样式影响运营后台。
- 旧版公开前端已备份到 `official_site/temp/legacy_frontend_20260831_023721`。

## site_20260826_03

- 管理后台新增邮件服务页，支持 SMTP 配置、测试邮件、给指定用户或邮箱发送邮件，并查看发送日志。
- 用户中心新增通知邮箱和邮件偏好，可分别开启或关闭反馈处理回复、帖子回复邮件提醒。
- 反馈提交改为要求有效联系邮箱；账号没有邮箱时可在提交反馈时填写并同步保存，便于后续处理回复通知。
- 论坛回复和反馈处理回复接入邮件通知，SMTP 未启用或发送失败不会影响原有站内通知和业务提交。

## site_20260826_02

- 项目页介绍校准为“把大 QMT 转成 miniQMT 形态来使用”的项目初心。
- 项目页内容宽度收窄，不再全屏铺满，阅读路径更集中。
- 新增转换链路、模块组件和使用场景图标，提高行情、交易、回调、更新反馈等模块的辨识度。

## site_20260826_01

- 项目页重构为“项目定位、桥接链路、运行流程、使用场景、下一步入口”的固定信息架构。
- 移除原项目页复杂架构动画和自动轮播说明，改为更清晰的本地桥接运行图。
- 优化项目页桌面、平板和手机端布局，减少首屏信息拥挤和按钮挤压。

## site_20260825_02

- 反馈页改为左侧菜单 + 右侧内容布局，默认展示公开反馈。
- 新提交反馈默认公开展示，提交完成后自动回到公开反馈列表。
- 管理后台反馈回复框增强 Ctrl+V 粘贴截图体验，图片会直接进入回复编辑区预览。

## site_20260825_01

- 管理后台反馈处理升级为列表 + 详情面板，点击反馈可进入详情处理。
- 反馈详情支持管理员回复，并可选择或粘贴截图作为回复附件。
- 反馈截图和处理回复截图在后台、我的反馈、公开反馈中自动显示缩略图，点击可放大预览。

## site_20260821_03

- 官网用户登录态改为持久 token，会话默认 365 天有效，并在用户持续访问接口时自动续期。
- 前端刷新页面后会用本地 token 和用户摘要恢复已登录状态，再通过 `/api/me` 校验；登录失败或过期时才清除本地状态。
- 登录弹窗不再保存明文密码，文案调整为“记住账号 / 保持登录状态”。
- 管理后台登录 token 同步持久化，退出后台时会通知后端删除对应 session。
- 静态资源版本更新为 `site_20260821_03`，生产环境已同步部署。

## site_20260821_02

- 论坛帖子列表支持点击整张帖子卡片进入讨论，并保留键盘 Enter / 空格进入能力。
- 回复图片上限调整为单次 10 张，粘贴或选择图片后在回复编辑框内显示缩略图。
- 回复和反馈图片改为站内弹窗预览，不再打开新的浏览器标签页。

## site_20260820_03

- 官网更新记录迁移到 `official_site/CHANGELOG.md`，根目录 `README.md` 不再记录官网页面迭代。
- 官网首页改为左侧项目说明、右侧动态架构动画，展示外部程序、传输通道、cfquant 本地桥接层、QMT 终端和官网更新分发之间的关系。
- 登录弹窗支持记住账号密码和下次自动登录；手动退出登录后会保留账号密码，但关闭自动登录，避免退出后再次自动进入。
- 修复帖子详情页登录成功后仍显示“登录后回复”的问题，登录态变化后会刷新当前帖子回复区。

## site_20260820_02

- 官网首页改为项目介绍首屏，论坛入口后移，项目定位、架构关系和下载入口更清晰。
- 项目首屏改成产品介绍页，移除旧的大截图主视觉，改用运行时示意图和更清楚的能力说明。
- 官网项目页支持默认进入、轮播暂停和减少动态效果设置，移动端排版也做了重新整理。

## site_20260820_01

- 官网 `cfquant.org` 增加项目下载与最新版本发布接口，支持展示更新日志、文件大小和 SHA256。
- 下载页支持本地更新包镜像和外部链接。
- 社区登录改为“用户名 / 手机号 / 邮箱 + 密码”，新注册用户使用 PBKDF2-SHA256 密码哈希；既有账号可在现有登录会话的用户中心设置密码。
