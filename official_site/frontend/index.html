把 QMT 的行情与交易能力封装成稳定的本地接口

cfquant 运行在本地 QMT Python 环境中，通过 Socket / Pipe / Web 服务把行情订阅、账户查询、交易请求、回调事件和更新能力统一暴露给外部程序，适合策略研发、实盘监控和自动化交易工具接入。

本地运行，不依赖云端托管 官网优先更新，GitHub 自动回退 围绕 QMT 行情与交易链路优化
