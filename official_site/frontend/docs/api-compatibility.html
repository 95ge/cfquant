接口兼容

cfquant 以大 QMT 策略环境真实暴露的 callable 为边界，优先覆盖行情、交易、查询和回调主链路。

xtdata xttrader Web API

状态定义

状态含义
已实现外部入口、桥接分发和大 QMT callable 调用链已经打通。
部分实现入口已存在，但返回结构、签名或真实 QMT 版本兼容性仍需验证。
条件可实现只有当前券商 QMT 暴露对应 callable 时才能使用。
不应实现属于 MiniQMT 客户端连接、本地数据目录或无等价大 QMT 能力。

交易与查询

  • order_stock、order_stock_async、cancel_order_stock 已走 QMT 交易 callable。
  • 资金、持仓、委托、成交查询已封装为 xtquant 风格对象。
  • 交易回调通过 WebSocket 和本地事件通道转发。
  • 信用专项查询和能力探测已接入，实际可用性取决于券商 QMT 暴露能力。

行情与基础数据

  • get_full_tick、get_market_data、get_market_data_ex 已实现。
  • 单股订阅、全推订阅、取消订阅和最新行情读取已接入。
  • 合约详情、板块成分、交易日历、ETF、期权、ST、因子等能力按 QMT callable 转发。
  • 本地大批量历史数据回测读取不建议走桥接主链路。

Web API 开放状态

接口能力
GET /api/status桥接端状态。
POST /api/data/full-tick实时 tick / 快照。
POST /api/data/market行情数据。
GET /api/account资金、持仓、委托、成交。
POST /api/order单笔下单。
POST /api/orders/batch批量下单。
POST /api/cancel撤单。
GET /api/callbacks / WS /ws/callbacks交易回调事件。

边界说明

MiniQMT 行情服务器连接管理、本地数据目录控制、直接导入原版 xtquant 兜底等能力不放进主链路。缺少真实大 QMT callable 的接口会返回明确错误，便于定位环境缺口。
