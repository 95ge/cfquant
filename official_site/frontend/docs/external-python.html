外部 Python 接入

外部策略可以按接近 xtquant 的方式导入 cfquant，由本地 Web 统一路由到在线的 QMT 入口脚本。

Python SDK 默认 auto 路由 行情 / 查询 / 交易

1. 安装本地包

在 cfquant 项目目录中安装开发模式包，让外部 Python 能直接导入当前项目代码。

cd D:\cfquant
pip install -e .

2. 推荐导入方式

from cfquant import xtdata
from cfquant.xttrader import XtQuantTrader
from cfquant.xttype import StockAccount

行情查询示例：

tick = xtdata.get_full_tick(["000001.SZ"])
print(tick)

账号查询示例：

account = StockAccount("2220009880")
trader = XtQuantTrader("", 0, account=account)
trader.start()

asset = trader.query_stock_asset(account)
positions = trader.query_stock_positions(account)
print(asset, positions)

3. 默认自动路由

默认 CFQUANT_TRANSPORT=auto。Web 服务启动后会写入运行注册信息，外部 cfquant 会优先通过 LTtx 发现 Web 统一路由；发现失败时再回退到通用 PipeHub。

  • 账号配置为高级模式时，Web 会优先走高级通道。
  • 高级通道不可用时，会回退到该账号的 ctypes 通用桥。
  • 外部策略通常不需要手写通道名。

4. 强制指定通道

排查问题或特殊部署时可以临时指定通道。

from cfquant import configure

configure(
    transport="web_lttx",
    host="127.0.0.1",
    port=2049,
    token="LTtx",
    web_request_channel="cfquant.web.request",
)
configure(
    transport="ctypes",
    pipe_name=r"\\.\pipe\cfquant_pipe_hub",
    timeout=15,
)

5. 接入前检查

  • Web 控制台已启动，QMT 侧入口脚本在线。
  • 账号绑定里资金账号、账户类型、模式和 QMT 目录正确。
  • 外部 Python 环境能导入 cfquant。
  • 先做只读查询，再逐步验证下单、撤单等交易接口。
