站内文档

运维更新

整理本地服务启停、日志定位、版本检查、Web 项目更新和 QMT 核心更新的日常路径。

启停脚本 日志定位 更新回滚

启停脚本

start_cfquant.bat      启动本地服务
stop_cfquant.bat       停止本地服务
restart_cfquant.bat    重启本地服务
启动cfquant.bat        中文启动脚本
停止cfquant.bat        中文停止脚本
重启cfquant.bat        中文重启脚本

日常运维通常使用重启脚本。重启只重启 Web 和 PipeHub，并保留 LTtx，避免外部 Python 自动发现入口中断。

日志目录

log/
  cfquant_startup.log
  cfquant_web_server.runtime.log
  cfquant_web_server.stdout.log
  cfquant_web_server.stderr.log
  cfquant_pipe_hub.stdout.log
  cfquant_pipe_hub.stderr.log
  lttx_server.stdout.log
  lttx_server.stderr.log
  cfquant_qmt_bridge.log

网页打不开或启动脚本报错时，优先看 cfquant_startup.log 和 cfquant_web_server.stderr.log。

运行数据目录

运行状态、配置数据库、缓存、截图和报告统一放到 runtime/，不进入发布包源码管理。

runtime/
  config/
  db/
  lttx/
  reports/
  media/
  cache/
  status/
  screenshots/

版本检查

Web 左上角会显示当前版本号。鼠标悬停可查看本地版本、远端版本、更新日志和版本检查失败原因。内网或无法访问外网时，版本探测失败不影响交易和行情。

更新策略

类型作用注意事项
Web 项目更新更新本地 Web、PipeHub、SDK 和脚本更新前生成备份，失败时回滚，完成后自动重启 Web。
QMT 核心更新更新每个已绑定 QMT 的 bin.x64/cfquant/不直接替换 QMT 中的加密入口脚本。
