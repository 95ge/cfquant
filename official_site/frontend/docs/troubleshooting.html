排障路径

先按问题类型定位日志和状态，再选择论坛讨论或提交带截图反馈，避免关键信息散落。

启动失败 桥接离线 交易与行情异常

网页打不开或启动失败

  1. 用 start_cfquant.bat --debug 启动，保留错误窗口。
  2. 检查 log/cfquant_startup.log 和 log/cfquant_web_server.stderr.log。
  3. 确认本机端口没有被其它程序占用。
  4. 把启动日志、Windows 版本、Python 路径和报错截图提交反馈。

QMT 桥接脚本离线

  1. 确认 QMT 中对应策略已启动，脚本没有停在异常窗口。
  2. 确认 Web 账号绑定中的 QMT 核心目录、账号类型和资金账号正确。
  3. 通用模式优先检查 CFQUANT_CTYPE_ALL_LOWLAT.py；高级模式同时检查普通 QMT 和极速交易端脚本。
  4. 查看 QMT 侧桥接日志语言和日志开关是否已保存。

账号查询没有数据

  • 先在 QMT 客户端确认账号已登录且有查询权限。
  • 普通账户使用 STOCK，信用账户使用 CREDIT。
  • 多 QMT 或多券商部署时，确认外部策略传入的账号与 Web 绑定一致。
  • 先验证资产和持仓只读查询，再验证委托、成交和交易动作。

行情订阅或全推异常

  • 确认 QMT 侧行情权限和证券代码后缀正确，例如 000001.SZ。
  • 全推订阅优先确认普通 QMT 桥在线。
  • 如只有部分代码异常，记录代码列表、周期、订阅方式和返回内容。

提交问题时需要带的信息

  • cfquant 核心版本、Web 版本、QMT 版本和运行模式。
  • 启动日志、Web 错误日志、QMT 桥接日志。
  • 复现步骤、调用代码片段、证券代码和账号类型。
  • 如果是界面问题，附上截图和浏览器地址。
