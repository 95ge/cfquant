部署指南

从官网下载项目包，启动本地 Web 控制台，在 QMT 中加载对应入口脚本，并完成账号绑定。

适合首次部署 通用模式优先 Windows / QMT 本机

1. 下载并解压项目包

进入官网“下载”页，优先使用最新项目包。解压到固定目录，建议路径不要包含临时目录或网盘同步目录。

D:\cfquant
打开下载页

2. 启动本地服务

在项目根目录执行启动脚本。正常启动后，Web 控制台和 PipeHub 会一起运行。

cd D:\cfquant
start_cfquant.bat

如果需要保留错误窗口，可使用前台或调试模式启动。

start_cfquant.bat --foreground
start_cfquant.bat --debug

3. 打开 Web 控制台

浏览器访问本机控制台，按初始化向导填写 QMT 核心目录、资金账号、账户类型和运行模式。

http://127.0.0.1:8765/
  • 账户类型普通账户选择 STOCK，信用账户选择 CREDIT。
  • QMT 核心目录建议选择大 QMT 的 bin.x64 目录。
  • 首次验证建议选择通用模式，低延迟交易需求再切高级模式。

4. 在 QMT 中加载入口脚本

模式QMT 侧脚本适用场景
通用模式qmt_scripts/CFQUANT_CTYPE_ALL_LOWLAT.py大多数部署、单账号验证、常规行情与交易。
极致模式qmt_scripts/CFQUANT_LITE.pyQMT 白名单限制严格、不能导入完整包的环境。
高级模式CFQUANT.py + CFQUANT_TRADE_LOWLAT.py普通 QMT 和极速交易端分工，追求更低交易链路延迟。

5. 验证在线状态

  • Web 顶部应显示 QMT 桥接脚本在线。
  • 账号页能查到资金、持仓、委托或成交数据。
  • 下载和更新页能显示当前核心版本、Web 版本和 SHA256。
  • 外部 Python 调用前，先确认 QMT 侧入口脚本没有报错。
