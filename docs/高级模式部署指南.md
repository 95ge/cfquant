# QMT高级模式部署指南

## 重要前提：先选通用模式或高级模式
cfquant 默认推荐通用模式，先用一个 QMT 跑通基础查询和交易。需要更低交易延迟时，再部署高级模式。

- 通用模式：在一个 QMT 中加载 `CFQUANT_CTYPE_ALL_LOWLAT.py`，行情、查询、下单、撤单和回调都走 ctypes 单文件桥。
- 高级模式普通 QMT：在普通 QMT 中加载 `CFQUANT.py`，主要负责资金、持仓、委托、成交和状态查询。
- 高级模式极速交易端：另开一个 QMT，在这个 QMT 中加载 `CFQUANT_TRADE_LOWLAT.py`，主要负责低延迟下单、撤单和交易回调。
- 本地服务：在 cfquant 目录运行 `start_cfquant.bat`，启动 LTtx 和 Web 控制台。

高级模式的“两端”不是指网页端和 QMT 端，而是指两个 QMT 终端：普通 QMT 桥和极速交易端桥。不要在同一个 QMT 里同时运行 `CFQUANT.py` 和 `CFQUANT_TRADE_LOWLAT.py`。通用模式和高级模式里的普通 QMT 可以部署在同一个 QMT 中；只有高级模式的极速交易端需要单独打开另一个 QMT。
