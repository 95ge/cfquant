# 高级模式部署指南

高级模式使用两个独立安装目录的 QMT：普通端负责行情、行情订阅和账户回调，交易端负责下单、撤单和账户查询。两个终端登录同一资金账号。只使用一个 QMT 时，选择[极致模式](极致模式部署指南.md)。

在 Web 控制台“绑定”页添加或编辑账号，选择“高级模式”，然后选择通信类型：

- **ctypes（默认）**：基于极致模式自包含入口，两端通过命名管道通信。普通端只监听行情请求通道并对外发布回调；交易端只监听交易请求通道，保留完成交易请求所需的本地回调处理。
- **socket**：沿用原高级模式的 LTtx 普通桥与交易桥；已有 socket 绑定继续保留此选择。

填写普通端和交易端两个 QMT 目录，分别完成 Python 运行库准备，再保存绑定。系统向两个目录同步代码、写入对应角色的身份配置，并部署托管策略。不能填写同一个安装目录或同一目录的 `bin.x64` / `python` 别名。

在绑定弹窗的“运行环境”页分别查看两端状态，通过“配置哪个 QMT”选择普通端或交易端，再为当前端下载或切换 Python 执行器。每端按自己的 QMT 版本显示可用执行器，普通端支持 Python 3.12 不代表交易端也支持。下载和重启只作用于当前目录；一端完成不代表另一端已就绪。新装终端尚未生成账号配置时，可先安装运行库，登录后再完成执行器配置。

启用自动启动时，两个终端均使用此绑定的登录配置；请先确认两端都能登录并具备账户交易权限。保存时若检测到 QMT 正在运行，按弹窗提示关闭并继续部署。

ctypes 高级模式与“同账号独立市场路由”互斥。切换通信类型后重新保存，并按部署提示重新启动两端 QMT，避免继续使用旧策略。系统自动识别模型账号，无需填写模型账号 Key。

API 配置使用 `mode="lite_advanced"` 表示 ctypes 高级模式，`mode="lttx"` 表示 socket 高级模式；主目录为 `qmt_dir`，交易端目录为 `qmt_trade_dir`。普通极致模式继续使用 `mode="lite"`。
