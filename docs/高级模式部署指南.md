# 高级模式部署指南

高级模式部署比较复杂，建议先部署通用模式后再尝试高级模式。本文内容来自 [QMT 部署教程](QMT部署教程.md) 中的“高级模式部署教程”章节。

## 一、部署前说明

- 高级模式和通用模式功能一致，但高级模式下单延迟要低很多。
- 高级模式下单延迟约 4ms 左右，这里的延迟是指从外部程序到 QMT 内部，不是指到交易所。
- QMT 到交易所的延迟不在本项目控制范围内。
- 只有一开始的两个 QMT 不同，其他部署方式和通用模式基本一样。
- 一般将 `qmt_scripts/CFQUANT_TRADE_LOWLAT.py` 放到第二个安装的 QMT 里，第一个 QMT 里部署 `qmt_scripts/CFQUANT.py`。
- 国泰海通无法部署高级模式。
