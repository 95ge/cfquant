# QMT 部署教程（当前版）

当前版本统一通过 Web 控制台部署，不再要求用户复制 Python 代码、创建 QMT 策略或手动放置入口脚本。

请阅读 [QMT 部署教程](QMT部署教程.md)，在初始化向导或“绑定”页面填写账号、账户类型、运行模式和 QMT 目录，勾选自动导入并管理 QMT 策略后保存。系统会自动准备核心包、身份配置和托管策略，并在页面显示部署结果。

保存后按页面提示重启或登录 QMT，再使用“检测连接”或账户查询确认上线。高级模式和独立市场需要分别配置对应的 QMT 目录。

旧版手工部署截图已移入项目根目录 `tem_delete/`，仅作历史留档，不属于当前部署流程，也不会随 Git 发布。
