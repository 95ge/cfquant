# cfquant 版本日志

这里记录 cfquant 的核心版本和 Web 控制台更新。普通用户只需要关注当前使用的部署模式和安装文档；遇到升级、回滚或版本不一致问题时，可以在这里查看变更。

## 版本日志

### web_20260904_10

- 删除中文命名的启动、停止和重启 bat 入口，保留英文命名入口作为唯一脚本。
- README、官网文档和 Web 控制台提示统一改用英文脚本名。
- 官网下载包随本次发布重新打包，确保下载内容与仓库一致。

### core_20260904_02 / web_20260904_09

- PyPI 安装后的 `cfquant` 命令增加中文启动提示，显示包版本、核心版本、Web 地址和 QMT 入口脚本目录。
- `cfquant qmt-scripts` 支持直接查看内置脚本目录和文件列表，`--open` 可在系统文件管理器中打开目录，`--output` 继续用于导出到 QMT 可加载目录。
- CLI 启动入口配置 UTF-8 标准输出，改善 Windows 中文路径和中文提示的显示。

### core_20260903_05 / web_20260903_07

- QMT 运行时版本上报改为读取已部署的 `cfquant` 包版本，并写入运行状态，便于确认实际启动的桥接版本。
- 修复交易明细查询参数错误、普通桥跨线程调用 QMT API 和部分 PipeHub 缓存问题。
- 账号启用后由 Web 后台预热资产和持仓，绑定页面不再等待长时间查询。

### web_20260902_05

- 接口调试页增加加载态、耗时和超时提示。
- 绑定页增加验证加载状态、保存状态和更清晰的 SH/SZ 市场路由展示。

### core_20260902_03

- Pipe 客户端断开后支持丢弃旧连接并重试。
- 改进账户缓存，避免瞬时连接错误覆盖有效数据。
- Windows 后台调用统一隐藏控制台窗口。

### web_20260902_04

- 共享行情源优先使用 SH/SZ 子桥。
- 同账号独立市场的持仓聚合增加子桥补查和市场过滤。

### web_20260902_03

- PipeHub 状态判断改为基于双向管道和 QMT 就绪状态，减少误报在线。

### core_20260902_02

- PipeHub 持续清理已断开的 SH/SZ 通道。
- 同账号独立市场入口分别使用 SH/SZ 配置。
- Lite 入口运行时上报市场标识和父桥 ID。

### web_20260902_02

- 绑定保存增加页面内状态提示。
- 小分辨率下绑定列表改为逐账号卡片布局。

### core_20260902_01

- SH/SZ 市场入口改为完整自包含文件，适配受限 QMT 环境。
- Lite 入口内置核心版本同步。

### web_20260902_01

- 同账号独立市场启用后，账号数据从 SH/SZ 子桥查询并合并展示。
- 主桥离线但市场子桥在线时，账号状态仍按市场路由判断。
- Web 回调筛选支持按主账号接收 SH/SZ 子桥事件。

### core_20260831_01

- 补充 QMT 行情、数据下载、数据读取、交易查询和异步查询示例。
- 删除容易与 `cfquant/tests/` 混淆的根目录 `tests/`。
- 明确建议使用 Python `3.12` 以下版本。

### web_20260831_01

- 优化系统更新页面、版本信息组件和 QMT 运行时版本持久化。

### web_20260830_02

- Web 重启和项目更新时保留 LTtx，完整停止时才停止 LTtx。
- 顶部版本组件增加 LTtx 状态、地址、PID 和保留策略。

### web_20260830_01

- Web 启动和保存模式配置时自动检查并预启动 LTtx。
- 通用模式和极致模式仍通过 PipeHub 路由请求。

### core_20260830_01

- 修复 `query_stock_asset` 返回形态与 xtquant 不一致的问题。
- 补充 `XtAsset`、`XtOrder`、`XtTrade`、`XtPosition` 等常用字段别名和常量。

### web_20260829_01

- 启动、停止和重启脚本增加环境检查、端口等待和失败日志。
- 增加启动日志文件，便于排查双击启动失败。

### core_20260828_02

- 新增同账号独立市场路由，支持上海、深圳两个独立 QMT 交易端。
- 新增 SH/SZ 市场入口脚本和 Web 配置项。

### core_20260828_01

- 新增极致模式 `CFQUANT_LITE.py`，QMT 侧只依赖标准库和 `ctypes`。
- Web 增加极致模式选项和部署教程。

### web_20260827_01

- 后台状态探测改为隐藏窗口执行，减少运行时黑窗闪现。

### core_20260821_02

- 扩展 `xtdata` 条件平替入口和通用 callable 转发。
- 订阅类条件入口支持 `callback_event` 事件转发。
- Web 接口页区分已实装、条件平替和不建议强行平替的能力。

### core_20260821_01

- QMT 入口增加运行时核心版本上报。
- Web 版本识别改为优先使用 QMT 运行时上报结果。

### core_20260818_01
