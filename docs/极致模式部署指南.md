# 极致模式部署指南

极致模式是当前唯一支持的 QMT 运行方式。它使用自包含的桥接入口，避免依赖 QMT 内部导入 `cfquant`，适配存在 Python 包白名单或导入限制的 QMT 环境。

用户只需下载并安装 QMT，无需预先登录。启动 CFQuant Web 控制台后，在绑定页填写 QMT 目录、资金账号和账户类型并保存，系统会自动安装 QMT Python 运行环境、部署自包含托管策略、启动 QMT 并等待通道上线。

## 自动部署内容

- 生成账户身份和桥接配置。
- 部署 `CFQUANT_LITE.py`（沪深独立市场使用对应的 `_SH` / `_SZ` 文件）。
- 通过 `EMBEDDED_RUNTIME_CONFIG` 注入账号和通道配置。
- 启动查询、交易、回调和 PipeHub 通道。
- 在 Web 页面显示环境安装、策略部署和在线检测进度。

用户无需复制代码、手动放置入口文件、在 QMT 中新建策略或预先登录 QMT。若 QMT 正在运行，保存绑定时按页面提示正常退出，系统完成部署后会自动重新启动。

## 部署验证

1. 绑定页面显示环境安装完成。
2. QMT 由系统启动，极致模式入口策略显示运行中。
3. 查询通道和交易通道均在线。
4. 接口测试能够返回行情、资金和持仓。

更新后保持 CFQuant 服务运行，重新保存绑定或使用更新操作，系统会重新部署入口。已经导入的旧策略不会因为仓库文件变化自动更新；以绑定页的部署代次和连接检测结果为准。

旧版通用模式、高级模式和手工导入流程已经废弃。
