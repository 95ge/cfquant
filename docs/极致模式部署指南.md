# 极致模式部署指南

极致模式用于 QMT 对 Python 包导入有白名单限制、无法正常导入 `cfquant` 核心包的环境，特别适合国泰君安君弘君智 QMT 这类白名单限制较严格的终端。QMT 侧只加载 `qmt_scripts/CFQUANT_LITE.py`，脚本内部自包含协议、PipeHub 通信和 `ctypes` 交易交互代码。

## 适用场景

- 国泰君安君弘君智 QMT 等终端可以运行 Python 脚本，但禁止导入项目里的 `cfquant` 包。
- 需要通过网页端或外部 Python 调用 QMT 行情、查询、下单和撤单能力。
- 可以在本机运行 `start_cfquant.bat` 启动 Web 服务和 PipeHub。

## 部署步骤

1. 启动本地服务：

   ```text
   start_cfquant.bat
   ```

2. 打开 Web 控制台：

   ```text
   http://127.0.0.1:8765/
   ```

3. 进入“绑定”页面，添加或编辑账号绑定，将运行模式选择为“极致模式”，并保存。

4. 将 `qmt_scripts/CFQUANT_LITE.py` 复制到 QMT 可加载的 Python 脚本目录。

5. 在 QMT 中加载并运行 `CFQUANT_LITE.py`。启动日志应优先显示中文，并包含：

   ```text
   cfquant 极致模式入口版本：lite_20260828_01
   cfquant 极致模式运行版本已上报
   ```

6. 回到 Web 控制台左上角版本弹窗，确认 QMT 运行时显示核心版本、入口脚本 `CFQUANT_LITE.py` 和入口版本。

## 注意事项

- 极致模式仍依赖本机 Web 服务和 PipeHub，QMT 侧不需要导入 `cfquant` 包。
- 更新项目后需要重新把新的 `CFQUANT_LITE.py` 放到 QMT 脚本目录，并重启该 QMT 脚本。
- 如果版本弹窗长时间显示“未上报”，先确认 Web 服务正在运行，再重启 QMT 脚本。
- 如果日志里只出现短暂的管道连接中断后又自动重连，通常是 PipeHub 或 QMT 脚本重启过程中的正常现象；如果持续反复，请检查同一个 `bridge_id` 是否被多个 QMT 脚本同时占用。
