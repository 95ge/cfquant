# 极致模式部署指南

极致模式适用于国泰君安、国泰海通等需要走极致模式的 QMT 环境。本文内容来自 [QMT 部署教程](QMT部署教程.md) 中的“极致模式部署教程”章节。

## 一、部署前说明

- 下载项目解压，或者通过 pip 安装后，在对应安装目录中找到我们的项目目录。
- 特别提醒：国泰君安和国泰海通的 QMT，需要走我们的【极致模式】。

## 二、复制项目目录

如图，将项目中的 `cfquant` 目录复制到你的 QMT 安装目录。

![复制 cfquant 目录](image-4.png)

## 三、安装 QMT Python 环境

打开 QMT，完成登录，并安装好相应的 Python 环境。已安装可忽略。

![安装 QMT Python 环境](image-5.png)

## 四、创建 Python 策略

打开大 QMT 里的模型研究界面，依次点击“新建策略”和“新建 Python 策略”。

![创建极致模式 Python 策略](image-11.png)

## 五、启动策略

启动我们的策略。

![启动极致模式策略](image-12.png)

## 六、重启 QMT

首次部署完成后，重启 QMT。

![重启 QMT](image-9.png)

## 七、网页端绑定账号

在网页界面中进行账号绑定。

![极致模式账号绑定](image-13.png)

## 八、接口调用测试

部署成功后，可以在网页端的接口中进行调用测试。

![极致模式接口测试](image-15.png)
