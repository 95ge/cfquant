# CFQuant QMT 部署教程

CFQuant 当前统一使用极致模式。用户只需下载并安装 QMT，无需预先登录；启动 CFQuant Web 控制台后，在前端完成账户绑定，系统会自动安装 QMT Python 运行环境、启动 QMT 并部署自包含桥接入口。

## 1. 准备环境

- Windows
- 已下载并安装大 QMT
- Python 3.8--3.12（源码启动脚本会自动选择或准备项目环境）
- CFQuant 源码包或已安装的 `cfquant` Python 包

启动 Web 控制台：

```powershell
start_cfquant.bat
# 或
cfquant run
```

访问 `http://127.0.0.1:8765/`，首次访问按初始化向导创建 Web 配置。

## 2. 保存账号绑定

在初始化向导或“绑定”页面填写：

- 资金账号
- 账户类型：`STOCK`、`CREDIT`、`FUTURE`、`FUTURE_OPTION` 或 `STOCK_OPTION`
- QMT 安装目录或 `bin.x64` 目录
- 模拟／实盘运行设置
- 是否启用策略自动运行

运行方式固定为极致模式，不再提供通用模式和高级模式选项。单个 QMT 运行账号时，保持“同账号独立市场路由”关闭；多 QMT 或多市场时，为每个实际目录分别建立绑定。

## 3. 自动安装和启动

保存绑定后，系统会按以下顺序自动处理：

1. 检查 QMT 目录和写入权限。
2. 安装或更新 QMT 所需 Python 运行环境。
3. 生成账户身份和桥接配置。
4. 部署 `CFQUANT_LITE.py` 自包含入口及必要的市场入口文件。
5. 自动启动绑定目录下的 QMT。
6. 等待入口策略和查询、交易通道上线。

用户不需要复制 Python 代码、手工导入策略、在 QMT 中新建模型或预先登录 QMT。部署进度和失败原因均显示在绑定页面；完成后点击“检测连接”，再查询资金、持仓、委托和行情。

如果 QMT 已经运行，系统会先提示正常退出以便更新入口；不会强制结束其他进程。重新保存绑定或执行连接检测即可触发恢复。

## 4. 运行状态

部署完成需要同时满足：

- Web 页面在线。
- QMT 已由系统启动。
- 极致模式入口策略显示运行中。
- 查询通道和交易通道在线。
- 接口测试可以返回行情，以及资金或持仓结果。

配置写入、策略部署和通道在线是三个独立阶段，不能只凭“保存成功”判断已完成。

## 5. 更新和故障处理

项目更新会保留本地配置、数据库和日志；更新桥接入口前会处理正在运行的托管 QMT，完成后自动重新启动。部署失败时先检查 QMT 目录、权限、Python 安装日志和账号配置，然后重新保存绑定。

常用日志：`log\startup\cfquant_startup.log`、`log\web\`。提交问题前请删除账号、密码、Token、订单和持仓等敏感信息。

旧版通用模式和高级模式入口、双 QMT 配置及手工导入流程已废弃，不适用于当前版本。
