# cfquant QMT 部署教程

首次初始化、添加账号和修改账号绑定都通过网页自动部署，不需要复制 Python 代码或在 QMT 中手工新建策略。

## 1. 准备环境和选择模式

安装并登录一次券商 QMT，确认资金账号和 QMT Python 环境可用，然后启动 cfquant Web 控制台。首次使用时按初始化表单创建管理员并配置账号。

| 模式 | QMT 目录 | 托管策略 |
|---|---|---|
| 通用 | 一个 QMT 安装目录或 `bin.x64` | 自动部署通用策略 |
| 极致 | 一个 QMT 安装目录或 `bin.x64` | 自动部署自包含策略，不依赖 QMT 侧导入 cfquant 包 |
| 高级 | 普通端和极速交易端两个不同的 QMT 目录 | 分别自动部署普通端和交易端策略 |

建议先使用通用模式；国泰君安、国泰海通 QMT 使用极致模式。同账号独立市场路由需要分别填写 SH/SZ 的 QMT 目录；单终端部署保持该选项关闭。

## 2. 保存账号绑定

在初始化向导或“绑定”页面填写资金账号、账户类型、模式和 QMT 目录，勾选“自动导入并管理 QMT 策略”，确认模拟／实盘配置后保存。普通账号和信用账号使用相同流程。

三个选项的含义不同：

- **自动导入并管理 QMT 策略**：自动生成、导入并维护账号对应的托管策略，新建绑定默认开启。
- **QMT 启动后自动运行**：登录 QMT 后自动运行托管策略，默认关闭。未勾选时，在“模型交易”运行已导入的托管策略。
- **自动启动 QMT**：保存后启动绑定主目录的客户端，默认关闭。它不会代替券商账号登录。

已有绑定的选项会保留，不会自动开启。自动部署必须填写有效的 QMT 目录；发现目录、权限或模型账号 Key 错误时，按部署提示修正后重新保存。

## 3. 重启或登录 QMT

保存后的弹窗显示部署结果及下一步操作：

- 未勾选自动启动：按提示重启对应 QMT 并登录。
- 已勾选自动启动：在启动后的 QMT 窗口登录。
- QMT 自身已设置自动登录：等待自动登录完成。
- **国金证券 QMT 目前不支持自动登录，每次启动后需手动输入密码登录。**
- 提示等待退出：正常退出 QMT，保持 cfquant Web 服务运行，等绑定列表显示模型配置完成后再启动。

高级模式及独立市场需要分别启动、登录各终端；自动启动选项仅作用于绑定的主 QMT 目录。不要同时运行旧版手工导入的入口。

## 4. 检查连接

点击“知道了”可直接关闭提醒。也可点击“检测连接”，检查对应通道上线，再通过“查资金”或持仓查询确认账号数据。

同一个 QMT 中，同一个资金账号只能启用一种 cfquant 模式。切换模式后，系统管理旧模式停用和新模式启用；具体状态以绑定页部署进度和通道连接为准。

详细导入过程、模型账号 Key、模式互斥和故障排查见 [Web 账号运行配置说明](Web账号运行配置说明.md)。

## 更新已有部署

升级项目后，保持 cfquant 服务运行，由策略管理器更新托管入口，并按绑定页提示重启 QMT。部署失败时修复错误并重新保存绑定，或使用绑定页的更新操作重试。配置写入成功、策略导入成功和通道在线是不同阶段，不能仅凭保存成功判断已上线。
