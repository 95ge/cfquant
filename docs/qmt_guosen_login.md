# 国信 iQuant 自动登录

国信 iQuant 在同一客户端提供“登录仿真”和“登录实盘”。cfquant 根据客户端正在使用的国信模式自动识别，不依赖安装目录名称，也不将通用 DLL 包含国信函数视为识别依据。

在账号绑定的自动登录设置中选择“国信 iQuant 登录环境”。默认实盘，需要仿真时选择“仿真”；已明确保存为仿真的绑定继续使用仿真。未设置环境的绑定按实盘处理。该设置仅在识别为国信版本时生效。API 配置字段为 `qmt_auto_login.login_environment`，可选值为 `simulation` 和 `live`，省略时为 `live`。

QMT 登录账号与资金账号分别配置，两者在部分券商相同，在国信 iQuant 中不同，不能互相替代：

- `qmt_auto_login.login_account`：QMT 客户端登录窗口使用的账号，用于客户端登录及匹配已保存的登录密码。
- `account_id`：真实资金账号，用于资金、持仓查询、交易请求、托管策略账户配置及资金账号就绪检查。

即使某券商的两个号码相同，也分别保存在对应字段中。程序只点击所选环境的唯一可用按钮，不会在失败后切换到另一环境。

平台登录完成后，程序读取账号管理页面，按资金账号与账号类型精确匹配。目标显示“登录成功”才报告整个登录流程成功；目标尚未登录时，通过客户端原生入口提交该账号的登录，单次会话不重复提交。不会点击“全选”或“选中登录”，也不会读取账号管理表中的密码。

国信客户端自行保存的其他账号自动登录规则仍由客户端执行。cfquant 不会替用户修改这些规则。

对于已打开但无法确认环境的国信主窗口，程序返回“无法确认实盘或仿真环境”，需要通过本绑定重新启动登录。找不到资金账号、账号类型不支持、权限或密码错误、界面变化时，平台登录成功不等于资金账号可用，程序会报告对应状态。

已在国信 iQuant v3.13（主程序文件版本 1.2.26.154，Qt 5.6.2 x64）验证仿真和实盘平台登录、绑定股票资金账号就绪检查、错误目标拒绝及已有会话环境检查。实盘验证覆盖正常退出、退出确认、重新启动、使用已保存凭据登录实盘和确认目标资金账号“登录成功”；未提交真实交易委托，不代表全部交易接口均已完成实盘验证。不会自动填写未保存的资金账号密码或处理未知验证弹窗。

桌面版使用嵌入式 Python 时，登录子进程使用与服务一致的代码版本，避免误加载旧安装包。国信自绘退出确认框仅在识别到明确退出提示时自动确认；无法识别的弹窗仍需人工处理。

首次初始化会在登录成功后正常退出 QMT，读取客户端生成的策略账户 Key，配置托管策略后重新启动。国信实盘 Key 中允许存在客户端生成的空字段，程序保留原始 Key，并核对资金账号和账户类型。初始化失败时保留具体错误，不会将这次正常退出当作崩溃而反复重启；修正配置后可从绑定页面重新启动。
