# QMT部署指南

## 重要前提：建议两端都部署
cfquant 需要本地服务端和 QMT 桥接端同时运行，完整功能才能正常使用。

- 本地服务端：在 cfquant 目录运行 `start_cfquant.bat`，启动 LTtx 和 Web 控制台。
- QMT 桥接端：把 `cfquant/`、`LTtx/`、`CFQUANT.py`、`CFQUANT_TRADE_LOWLAT.py`、`tx.py` 放到 QMT 的 Python 策略目录，并在 QMT 中加载两个桥接脚本。

只启动网页端时，可以打开控制台和配置页面，但无法真正调用 QMT 的行情、交易和账号能力；只部署 QMT 脚本但不启动本地服务端，网页端和外部 Python 也无法连接。实际使用时建议两端都部署，并在网页端完成桥接端和账号绑定。
