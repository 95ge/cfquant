# 通用模式部署指南

通用模式建议优先使用。请按 [QMT 部署教程](QMT部署教程.md) 在网页填写账号、模式和 QMT 目录并保存，系统自动完成部署，然后按提示重启或登录 QMT。无需手动复制代码或新建策略。

旧版手工部署截图已移入项目根目录 `tem_delete/`，不属于当前部署流程。

## 一、部署前说明

- 下载项目解压，或者通过 pip 安装后，在对应安装目录中找到我们的项目目录。
- 本文以项目下载解压作为示例，使用国金证券 QMT 作为示例，其他证券公司 QMT 按同样方式安装即可。
- 特别提醒：国泰君安和国泰海通的 QMT，需要走我们的【极致模式】。

## 二、填写 QMT 目录并自动复制核心包

在 Web 初始化或“绑定”页面填写 QMT 安装目录或 `bin.x64`。保存账号配置时，系统会自动将项目中的 `cfquant` 目录复制到对应的 `bin.x64/cfquant`；如果目录不存在或没有写入权限，页面会提示异常，修正目录后重新保存即可。


## 三、安装 QMT Python 环境

打开 QMT，完成登录，并安装好相应的 Python 环境。已安装可忽略。


## 四、重启或登录 QMT

首次部署完成后，重启 QMT。


## 五、确认部署成功

在网页界面中进行账号绑定。
