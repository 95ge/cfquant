# CFQuant Pro 登录设备管理

登录官网后，点击右上角头像进入个人中心。在左侧选择“登录设备”，可以查看桌面端设备记录、客户端版本、最近活动时间，以及撤销不再使用的设备。

登录设备与“我的 CFQuant 部署”分别管理：前者是官网账号的桌面登录会话，后者是远程运维部署。

## 设备数量

默认不限制设备数量。个人账号可选择“不限制”，或填写 1–10000 的自定义上限。

- 设置只应用于当前账号，不改变套餐、授权期限或产品能力。
- 调低上限不会自动撤销已登录的设备；超过上限时阻止新设备登录，已有有效设备仍可重新登录。
- 同一设备标识重新登录替换原会话，不重复占用名额。
- 不同安装目录、开发版本或删除配置后，可能使用不同设备标识。
- 手动撤销设备后，对应会话将失效；重新登录仍需验证账号和当前授权状态。

历史套餐默认的 1、3、20 台额度迁移为不限制；明确由管理员设置的额度保留，可由个人账号在本页调整。公共账号不提供桌面端登录和设备设置。

## 官网接口

接口使用官网用户会话，与本地 CFQuant 管理 API 的授权分开。

| 接口 | 用途 |
| --- | --- |
| `GET /api/me/desktop-sessions` | 读取当前用户的桌面设备记录 |
| `POST /api/me/desktop-device-limit` | 更新当前用户的设备数量，JSON 为 `{"device_limit": 0}`；0 表示不限 |
| `POST /api/me/desktop-sessions/{id}/revoke` | 撤销属于当前用户的桌面会话 |

`device_limit` 必须为 0–10000 的整数。数量设置接口不会接受其他用户标识、套餐或授权能力变更；请求中的额外字段不会用于修改这些配置。
